# Release

ROM-файлы для Вектора-06Ц.

## music-roms/

Саундтреки и музыкальные ROM. Звук: ВИ53 (3 канала) + AY-3-8910 (шум/ударные).

| ROM | Описание |
|-----|----------|
| jackal.rom | Саундтрек Jackal (NES), 8 треков |
| castlevania.rom | Саундтрек Castlevania (NES), 9 треков |
| ducktales2.rom | Саундтрек DuckTales 2 (NES), 6 треков |
| supermario.rom | Саундтрек Super Mario Bros (NES), 13 треков |
| nes_drums.rom | 16 шумовых инструментов NES + демо |
| drums.rom | Демо ударных AY-3-8910, 7 инструментов |
| synth.rom | Партитурный синтезатор, 6 тестов |

## tests/

Тесты графических режимов и библиотечных модулей.

| ROM | Описание |
|-----|----------|
| 512x256.rom | Тест режима 512×256 (4 цвета) |
| cls.rom | Тест скорости очистки экрана |
| clrs.rom | Смена палитры во время развёртки |
| dt2.rom | Вывод картинки 256×256 (RLE) |
| dt2_512.rom | Вывод картинки 512×256 (2 цвета) |
| dt2_lz.rom | LZ-распаковка картинки 256×256 |

---

Сборка: `make` в корне репозитория.
