# Stage 1. Общее исследование карты памяти putup.rom

## Общие сведения о ROM

| Параметр | Значение |
|---|---|
| Файл | `src/putup.rom` |
| Размер | 17664 байт (0x4500) |
| Диапазон в памяти | 0x0100 — 0x45FF |
| Архитектура | КР580ВМ80А (Intel 8080) |
| Режим экрана | 256×256, 1 плоскость (mode512 = false) |
| VRAM base | 0xC000, размер 8192 байт |

## Точка входа и инициализация

```
0x0100: DI                  ; Запрет прерываний
0x0101: JMP 0x0B57          ; Переход на основную точку инициализации
```

### Подпрограмма инициализации (0x0B57):

```
0x0B57: DI
0x0B58: LXI SP, 0100        ; Стек в области 0x0000-0x00FF
0x0B5B: LXI H, 8000         ; Начало очистки RAM
0x0B5E: MVI M, 00           ; Обнуление
0x0B60: INX H
0x0B61: MOV A, H
0x0B62: XRA M
0x0B63: JNZ 0B5E            ; Цикл очистки 0x8000-0xFFFF
0x0B66: CALL 0383           ; Подпрограмма инициализации #1
0x0B83: CALL 0401           ; Подпрограмма инициализации #2
0x0B86: LXI H, 7418         ; Загрузка графики в VRAM
0x0B89: LXI D, 2F61         ; Источник данных в ROM
0x0B8C: MVI B, 1C           ; 28 циклов × 8 байт = 224 байта графики
0x0B8E-0x0BA5: Цикл копирования LDAX D → MOV M,A
0x0BC2: CALL 3D4E           ; Дополнительная инициализация
0x0BE7: CALL 1BE5           ; Подпрограмма настройки
```

После инициализации — основной цикл программы с чередованием:
- `CALL 014F` (SHLD 0x0B53 — сохранение указателя)
- `CALL 0321` / `CALL 0331` (обработка данных)
- Работа с объектами по адресам: 0x50A0, 0x5229, 0x5287, 0x506B, 0x506E

## Векторы прерываний

| Адрес | Код | Назначение |
|---|---|---|
| 0x0000 | `JMP 0x0B57` | Вектор сброса (RST 0) |
| 0x0038 | `JMP 0x03A4` | Вектор прерывания (RST 7) |

## Карта памяти (активность за ~5 секунд работы)

### Системная область (0x0000–0x00FF)

| Блок | Чтение | Запись | Назначение |
|---|---|---|---|
| 0x0000-0x00FF | ✅ | ✅ | Вектора прерываний, рабочий стек (SP ≈ 0x00F8) |

### ROM-область (0x0100–0x45FF)

| Блок | Чтение | Запись | Назначение |
|---|---|---|---|
| 0x0100-0x0CFF | ✅ | ✅ | Код программы (выполнение + self-modifying данные) |
| 0x0D00-0x1AFF | ❌ | ❌ | Неактивные данные ROM (таблицы, не используются) |
| 0x1B00 | ✅ | ❌ | Табличные данные |
| 0x1C00-0x26FF | ❌ | ❌ | Неактивные данные ROM |
| 0x2700-0x2FFF | ✅ | ❌ | Табличные данные (графики/константы) |
| 0x3000-0x4000 | ✅ | ❌ | Код и данные ROM |
| 0x4100 | ❌ | ❌ | Неактивный блок |
| 0x4200-0x4400 | ✅ | ❌ | Код и данные ROM |
| 0x4500 | ❌ | ❌ | Последний блок ROM (хвост) |

### RAM-область (0x4600–0x7FFF)

| Блок | Чтение | Запись | Назначение |
|---|---|---|---|
| 0x4600-0x4FFF | ❌ | ❌ | Свободная RAM, не используется |
| 0x5000-0x53FF | ✅ | ✅ | **Рабочие данные программы** (переменные, объекты) |
| 0x5400-0x5FFF | ❌ | ❌ | Неактивная RAM |
| 0x6000-0x7FFF | ✅ | ✅ | **Данные графики/спрайтов** (загружаются при инициализации) |

### VRAM и верхняя RAM (0x8000–0xFFFF)

| Блок | Чтение | Запись | Назначение |
|---|---|---|---|
| 0x8000-0xBFFF | ✅ | ✅ | Рабочая RAM (буферы, данные) |
| 0xC000-0xDFFF | ✅ | ✅ | **VRAM Plane 0** (текстовый экран 256×256) |
| 0xE000-0xFFFF | ✅ | ✅ | **VRAM / верхняя RAM** |

> **Примечание:** `execute_activity = 0` во всех блоках — артефакт классификации эмулятора. Код выполняется из ROM-области (0x0100-0x45FF).

## Анализ VRAM (0xC000, 8192 байт)

VRAM содержит **текстовый экран 256×256** с повторяющимися паттернами:

- **Рамки/границы**: паттерн `FC FE FE FE FE FE FE 00 FF FF FF FF FF FF 7F 00` — повторяющиеся прямоугольные рамки
- **Символы/глифы**: паттерны `C6 C6 FC CC CC F8 00` (буква "A"), `FC FE FE FE FC CC CC CC` (буква "H") и другие
- **Вертикальные полосы**: `03 0F FF FF 7E 3C 00` — декоративные элементы
- **Специальные данные**: `FF FF FF FF EF B2 99 02 00 00 11 DC 67 43 26 00` — возможно цветовая палитра или спрайт

## Предварительные выводы

1. **putup.rom** — это программа с текстовым экраном 256×256, использующая AY-3-8910 для звука
2. Программа активно сканирует клавиатуру (порт 0x01) в ожидании нажатия
3. При старте загружает данные из ROM (0x5000) и графику (0x2F61→0x7418)
4. VRAM содержит текстовые символы в рамках — вероятно, заставка или меню
5. Рабочие переменные расположены в области 0x08xx и 0x5000-0x53FF
6. Обработчик прерываний находится по адресу 0x03A4
7. Программа использует диспетчер вызовов через таблицу адресов (0x01BC)
8. Область 0x6000-0x7FFF содержит загруженную графику/спрайты
