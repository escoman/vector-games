# Stage 1. Общее исследование карты памяти и активности программы

**ROM:** `./src/putup.rom`
**Время наблюдения:** 5 секунд работы программы
**Состояние:** Заставка игры, ожидание нажатия SPACE

---

## 1. Загрузка и инициализация

ROM загружен с origin `0x0100`, PC после загрузки = `0x0000`.
Программа проходит полную инициализацию: тест ОЗУ, настройка PIA/ВИ53, распаковка данных из ROM в RAM.

**Точка входа (0x0000):**
- Инициализация ВВ55 #1 и #2 (порты 0x00–0x07)
- Настройка стека: SP = 0xDCF0 (позже перемещается в 0x00FE)
- Настройка ВИ53 (таймер/звук, порты 0x08–0x0B)
- Запись палитры через порт 0x0C
- Распаковка данных из ROM в область RAM 0x0800–0x45FF
- Переход к основному циклу

### 2.5. VRAM-блоки (0x8000–0xFFFF)

Все 128 блоков VRAM имеют одинаковую базовую активность:
- Чтение: 256/блок
- Запись: 576–880/блок (чередование паттернов)

Блоки с записью ~832–880: 0x8400–0x8B00, 0x9400–0x9B00, и т.д. (каждые 16 блоков)
Блоки с записью ~576–648: 0x8000–0x8300, 0x8C00–0x8F00, и т.д.

**Наблюдение:** Паттерн записи VRAM соответствует поблочной перерисовке экрана (отрисовка заставки).

## 3. Видеопамять (VRAM)

### 3.1. Режим экрана

| Параметр | Значение |
|----------|----------|
| Разрешение | 256×256 (не 512×256) |
| Скроллинг | 0–253 (анимированный) |
| VRAM base | 0xC000 |
| Пикселей на байт | 8 |

### 3.2. Плоскости VRAM

| Плоскость | Адрес CPU | Размер | Активность |
|-----------|-----------|--------|------------|
| Plane 0 | 0xE000 | 8 192 B | R+W (256 R / 576–880 W на блок) |
| Plane 1 | 0xC000 | 8 192 B | R+W (256 R / 576–880 W на блок) |
| Plane 2 | 0xA000 | 8 192 B | R+W (256 R / 576–880 W на блок) |
| Plane 3 | 0x8000 | 8 192 B | R+W (256 R / 576–880 W на блок) |

**Наблюдение:** Все 4 плоскости активно читаются и записываются — полная перерисовка экрана.

## 5. Трассировка портов ввода-вывода (I/O Trace)

### 5.1. Наблюдаемая операция

За 1000 событий трассировки обнаружен **единообразный паттерн**:

| Порт | Тип | Значение | Частота | Назначение |
|------|-----|----------|---------|------------|
| 0x01 | IN | 0xE2 | 1000 из 1000 | Port C ВВ55 #1 (клавиатура) |

**Паттерн:** `IN 01` → значение `0xE2` — непрерывный опрос клавиатуры.

### 5.2. Интерпретация

Порт 0x01 — **Port C КР580ВВ55 #1**:
- Бит 0 (0): магнитофон — нет сигнала
- Бит 1 (1): клавиша СС — не нажата (active low)
- Бит 2 (0): клавиша УС — не нажата
- Бит 3 (0): РУС — не активен
- Биты 4–7 (1110): результат сканирования матрицы клавиатуры

**0xE2 = 1110 0010b** — ни одна клавиша не нажата, программа ждёт SPACE.

### 5.3. Порты, зафиксированные в ROM-коде (0x0000–0x07FF)

| Порт | Операция | Назначение |
|------|----------|------------|
| 0x00 | OUT | Control Word ВВ55 #1 |
| 0x01 | IN | Port C ВВ55 #1 (клавиатура/магнитофон) |
| 0x02 | OUT | Port B ВВ55 #1 (бордюр + режим 512px) |
| 0x03 | OUT | Port A ВВ55 #1 (скроллинг + маска клавиатуры) |
| 0x04 | OUT | Control Word ВВ55 #2 |
| 0x05 | OUT | Port C ВВ55 #2 |
| 0x06 | IN/OUT | Port B #2 (Covox) |
| 0x07 | OUT | Port A #2 |
| 0x08 | OUT | Control Word ВИ53 |
| 0x0B | OUT | Счётчик канала 0 ВИ53 |
| 0x0C | OUT | Запись палитры (RRRGGGBB) |
| 0x10 | OUT | Банковая память |

## 6. Ключевые наблюдения

1. **ROM занимает 0x0100–0x07FF** (~1.75 КБ кода). ROM-код не перезаписывается (write_count=0 для всех ROM-блоков).

2. **Распаковка данных:** ROM распаковывает данные в RAM 0x0800–0x45FF. Блоки 0x0900–0x45FF содержат распакованные данные игры (has_content=true).

3. **Горячие точки чтения:**
   - 0x0100 (2.77M) — ROM-код
   - 0x0C00 (1.31M) — данные игры (интенсивное чтение)
   - 0x0000 (1.1M R / 1.1M W) — ISR / системные переменные
   - 0x0800 (405K) — распакованные данные

4. **Активные записи RAM:**
   - 0x0B00 (17 530 записей) — анимация / обновляемые данные
   - 0x0800 (9 582 записей) — обновляемые данные
   - 0x0000 (1.1M записей) — ISR-обработка

5. **VRAM:** Все 4 плоскости активно перерисовываются. Паттерн записи (576–880/блок) соответствует отрисовке заставки.

6. **Опрос клавиатуры:** 100% I/O-трассы — `IN 0x01` (Port C) со значением 0xE2. Программа ждёт нажатия SPACE.

7. **Стек:** SP=0x00FE — в нулевой странице, что нетипично. Возможно, стек перемещён после распаковки.

8. **Скроллинг:** Анимированный (0–253), что указывает на эффект прокрутки на заставке.
