# fire — демонстрация огня (beam-race)

![fire](screen.png)

Классический демосценный эффект «огонь»: тепловая карта вычисляется в ОЗУ-буфере
по алгоритму Палмера/Ландона (случайное затухание + усреднение соседних строк,
смещение по лучу ±2) и выводится на экран гонкой за электролучом — каждая
строка считается и пишется прямо перед тем, как на неё попадает луч.

- Режим: 256×256, 16 цветов (палитра градиента пламени).
- Огонь поднимается от нижнего края; фон остаётся чёрным — отсюда тонкая
  полоса пламени на снимке.
- Вся логика — в `fire.asm` (горячий путь на ассемблере), `main.c` — каркас.

## Сборка

```bash
make          # собрать fire.rom
make deploy   # собрать + положить в ROMS эмулятора PPSSPP
make full     # clean + deploy
```

См. также [`../fire2`](../fire2) — улучшенная версия (буфер 64×64 → экран 256×256)
с разбором оптимизаций в [OPTIMIZATION.MD](../fire2/OPTIMIZATION.MD).
