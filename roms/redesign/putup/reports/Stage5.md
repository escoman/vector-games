# Stage 5. Исследование прерываний

**ROM:** `./src/putup.rom`
**Метод:** Дизассемблирование ISR + IO-трейс + анализ документации VECTOR_VERIFIED.md
**RDB объектов:** 61 (добавлено 6 новых)

---

## 1. Аппаратные прерывания Vector-06C

Согласно документации (VECTOR_VERIFIED.md):

| Параметр | Значение |
|----------|----------|
| Источник | VBlank (кадровый) |
| Тип | RST 7 (opcode FFh) |
| Вектор | 0x0038 |
| Частота | ~50 Гц (50.08) |
| Маскирование | EI/DI |
| Момент | Начало обратного хода (строка 0, пиксель 174) |

Единственное аппаратное прерывание — **RST 7 (VBlank)**. Эмулятор инжектирует opcode 0xFF при наступлении VBlank, если прерывания разрешены (IFF=1).

---

## 2. Векторы прерываний в памяти

Анализ области 0x0000–0x003F (векторное пространство):

| Адрес | Содержимое | Назначение |
|-------|-----------|-----------|
| 0x0000 | `JMP 0x0B57` | Вектор RESET (установлен func_rom_init) |
| 0x0038 | `JMP 0x03A4` | Вектор RST 7 → func_isr |

Оба вектора устанавливаются в `func_rom_init` (0x0383):
```asm
; func_rom_init (0x0383)
MVI A, C3           ; opcode JMP
OUT 10              ; сброс банков (квазидиск)
STA 0038            ; [0x0038] = C3 (JMP)
LXI H, 03A4         ; адрес ISR
SHLD 0039           ; [0x0039-3A] = 0x03A4
STA 0000            ; [0x0000] = C3 (JMP)
LXI H, 0B57         ; адрес main_init
SHLD 0001           ; [0x0001-02] = 0x0B57
EI                  ; разрешить прерывания
RET
```

## 3. func_isr (0x03A4) — обработчик RST 7

### 3.1. Структура ISR

ISR состоит из **3 фаз**:

```
┌─────────────────────────────────────────────────────┐
│ Фаза 1: Счётчик кадров + палитра/скроллинг        │
│   [0x08DF]++ (кадровый счётчик)                     │
│   if [0x08C3] != 0:                                 │
│     [0x08C3]--                                      │
│     16 цветов: [0x08DB] → OUT 0x0C (палитра)       │
├─ 8× { port 0x03 ← value, IN 0x02 (клавиши) }
│                                                      │
│ Фаза 2: PIA + клавиатура                            │
│   0x8A → port 0x00 (Port A = input)                 │
│   0x80 → port 0x00 (latch)                          │
│   8x: scroll → OUT 0x03, IN 0x02 (клавиши)         │
│                                                      │
│ Фаза 3: Post-ISR                                    │
│   0x88 → port 0x00 (Port B = output)                │
│   0x02 → port 0x01 (Port B data)                    │
│   [0x08CF] → port 0x03 (скроллинг)                  │
│   [0x08C4] → port 0x02 (бордюр)                     │
│   CALL func_isr_game_state (0x3858)                  │
│   POP PSW/B/D/H; EI; RET                            │
└─────────────────────────────────────────────────────┘
```

### 3.2. Полный дизассембли func_isr

```asm
; === ВХОД ISR ===
0x03A4: PUSH H              ; сохранить H
0x03A5: PUSH D              ; сохранить D
0x03A6: PUSH B              ; сохранить B
0x03A7: PUSH PSW            ; сохранить PSW

; === ФАЗА 1: Счётчик + палитра ===
0x03A8: LXI H, 08DF         ; HL → счётчик кадров
0x03AB: INR M               ; [0x08DF]++ (каждый VBlank)
0x03AC: LXI H, 08C3         ; HL → флаг анимации
0x03AF: CMP L               ; A = 0, сравнить с L
0x03B0: ORA A               ; проверить A
0x03B1: JZ 03D1             ; если [0x08C3]==0 → пропуск палитры
0x03B4: DCR M               ; [0x08C3]-- (декремент таймера)
0x03B5: LXI D, 100F         ; D=16 (счётчик), E=15 (задержка)
0x03B8: LHLD 08DB           ; HL = указатель на данные палитры
0x03BB: MOV A, E            ; A = E (border color)
0x03BC: OUT 02              ; записать бордюр
0x03BE: MOV A, M            ; A = [HL] (цвет палитры)
0x03BF: OUT 0C              ; записать цвет
0x03C1: DCR C               ; задержка
0x03C2: OUT 0C              ; повторить цвет (timing)
0x03C4: NOP                 ; задержка
0x03C5: NOP
0x03C6: NOP
0x03C7: DCX H               ; HL-- (указатель растёт назад)
0x03C8: OUT 0C              ; записать следующий цвет
0x03CA: DCR E               ; E-- (счётчик задержки)
0x03CB: DCR D               ; D-- (счётчик цветов)
0x03CC: OUT 0C              ; записать цвет
0x03CE: JNZ 03BB            ; повторить 16 раз

; === ФАЗА 2: PIA + клавиатура ===
0x03D1: MVI A, 8A           ; PIA: Port A = input
0x03D3: OUT 00
0x03D5: LXI H, 08D3         ; HL → таблица таймера
0x03D8: MVI A, FE           ; начальное значение скроллинга
0x03DA: PUSH PSW            ; сохранить A
0x03DB: OUT 03              ; записать скроллинг
0x03DD: IN 02               ; прочитать Port B (клавиатура)
0x03DF: MOV M, A            ; [HL] = результат
0x03E0: POP PSW             ; восстановить A
0x03E1: INX H               ; HL++ (следующая строка)
0x03E2: RLC                 ; сдвиг битов (0xFE→0xFD→0xFB→...)
0x03E3: JC 03DA             ; если не переполнение → повторить

; === ФАЗА 3: Post-ISR ===
0x03E6: MVI A, 88           ; PIA: Port B = output
0x03E8: OUT 00
0x03EA: MVI A, 02           ; Port B data = 0x02
0x03EC: OUT 01
0x03EE: LDA 08CF            ; A = [0x08CF] (скроллинг)
0x03F1: OUT 03              ; записать скроллинг
0x03F3: LDA 08C4            ; A = [0x08C4] (бордюр)
0x03F6: OUT 02              ; записать бордюр
0x03F8: CALL 3858           ; func_isr_game_state
0x03FB: POP PSW             ; восстановить PSW
0x03FC: POP B               ; восстановить B
0x03FD: POP D               ; восстановить D
0x03FE: POP H               ; восстановить H
0x03FF: EI                  ; разрешить прерывания
0x0400: RET                 ; возврат
```

### 3.3. Параметры func_isr

| Свойство | Значение |
|----------|----------|
| **Вход** | Нет (аппаратное прерывание RST 7) |
| **Выход** | Палитра/скроллинг/бордюр через порты; обновление состояния игры |
| **Модифицирует** | A, C, D, E (H, D, B, PSW сохраняются) |
| **Стек** | PUSH H,D,B,PSW → POP PSW,B,D,H → EI → RET |

## 4. Фаза 1: Палитра и скроллинг

### 4.1. Палитра (16 цветов)

Когда `[0x08C3] != 0`:
- `[0x08C3]` декрементируется (таймер анимации)
- Из `[0x08DB]` читаются 16 байт цветов
- Каждый цвет записывается в порт `0x0C` (палитра)
- Указатель `[0x08DB]` декрементируется (DCX H)
- Между записями — NOP-задержки для тайминга

### 4.2. Записи в порт 0x03 (скроллинг/видео)

В фазе 2 ISR выполняется 8 записей в порт 0x03 с убывающими значениями:
```
0xFE → 0xFD → 0xFB → 0xF7 → 0xEF → 0xDF → 0xBF → 0x7F
```
Каждое значение = сдвиг нуля в младших битах. Между записями — чтение порта 0x02 (клавиатура).

**Примечание:** В игре отсутствует скроллинг экрана. Записи в порт 0x03 в контексте ISR, вероятно, связаны с видеотаймингом или процедурой сканирования клавиатуры, а не с перемещением экрана.

### 4.3. IO-трейс фазы 1

Подтверждено IO-трейсом (15 OUT-событий):
```
OUT 0x00 = 0x8A    ; PIA Port A = input
OUT 0x03 = 0xFE    ; порт 0x03 (видео/тайминг)
IN  0x02           ; keyboard
OUT 0x03 = 0xFD    ; порт 0x03
IN  0x02           ; keyboard
... (8 итераций)
```

## 5. Фаза 3: Post-ISR

После палитры/клавиатуры:

```asm
MVI A, 88     ; PIA: Port B = output
OUT 00
MVI A, 02     ; Port B data = 0x02
OUT 01
LDA 08CF      ; scroll value
OUT 03        ; записать скроллинг
LDA 08C4      ; border color
OUT 02        ; записать бордюр
CALL 3858     ; func_isr_game_state
```

IO-трейс подтверждает:
```
OUT 0x00 = 0x88
OUT 0x01 = 0x02
OUT 0x03 = 0x00    ; порт 0x03 (видео)
OUT 0x02 = 0x00    ; border
OUT 0x0B = 0xB0    ; timer (sound)
OUT 0x0B = 0x0A    ; timer (sound)
```

## 6. func_isr_game_state (0x3858)

Подфункция ISR, вызываемая в фазе 3:

```asm
0x3858: PUSH H
0x3859: LHLD 3854         ; загрузить указатель на данные
0x385C: SHLD 0B41         ; сохранить в temp
0x385F: POP H
0x3860: PUSH H
0x3861: LHLD 0B41
0x3864: INX H             ; +2 (пропустить 2 байта)
0x3865: INX H
0x3866: MOV A, M          ; A = state byte (offset +2)
0x3867: POP H
0x3868: MOV B, A          ; B = state
0x3869: LDA 383A          ; A = toggle counter
0x386C: ADD A             ; A *= 2
0x386D: JNZ 3875          ; если != 0 → skip
0x3870: MVI A, 00         ; сброс
0x3872: STA 383A          ; [0x383A] = 0
0x3875: CPI 00
0x3877: CZ 3890           ; если 0 → вызов 0x3890
0x387A: CALL 3BCA         ; вызов 0x3BCA
0x387D: CALL 3C7D         ; вызов 0x3C7D
```

| Свойство | Значение |
|----------|----------|
| **Вход** | Нет (читает из `[0x3854]`) |
| **Выход** | Обновление состояния игры |
| **Модифицирует** | A, B, H |

## 7. Переменные ISR

| Адрес | Имя | Размер | Назначение |
|-------|-----|--------|-----------|
| 0x08C3 | `var_frame_counter` | 1 | Флаг анимации. Когда ≠0 — палитра активна. Декрементируется каждый кадр. |
| 0x08C4 | `var_border_color` | 1 | Цвет бордюра. Записывается в порт 0x02 в фазе 3. |
| 0x08CD | `var_frame_count_isr` | 1 | Указатель данных палитры (используется с DCX H). |
| 0x08CF | `var_vram_scroll` | 2 | Значение скроллинга. Записывается в порт 0x03. |
| 0x08DB | `var_data_ptr` | 2 | Счётчик кадров ISR. Инкрементируется каждый VBlank. |
| 0x08DF | `var_isr_frame_count` | 1 | Счётчик кадров ISR (INR M). |
| 0x383A | `var_isr_state_toggle` | 1 | Переключатель состояния для func_isr_game_state. |
| 0x3854 | `var_isr_data_ptr` | 2 | Указатель на структуру состояния игры. |
| 0x0B41 | `var_isr_temp_ptr` | 2 | Временная копия var_isr_data_ptr. |

## 9. Временная диаграмма ISR

```
VBlank (~50Hz)
    │
    ├─ RST 7 → 0x0038 → JMP 0x03A4
    │
    ├─ PUSH H,D,B,PSW (сохранение контекста)
    │
    ├─ [0x08DF]++ (кадровый счётчик)
    │
    ├─ if [0x08C3] != 0:
    │   ├─ [0x08C3]--
    │   ├─ 16× { border→0x02, color→0x0C, delay }
    │   └─ [0x08DB] обновляется (DCX H)
    │
    ├─ PIA setup (0x8A→0x00)
    ├─ 8× { port 0x03 ← value, IN 0x02 }
    │
    ├─ PIA setup (0x88→0x00, 0x02→0x01)
    ├─ [0x08CF]→0x03 (скроллинг)
    ├─ [0x08C4]→0x02 (бордюр)
    ├─ CALL func_isr_game_state
    │
    ├─ POP PSW,B,D,H
    ├─ EI
    └─ RET
```

## 10. Ключевые выводы

1. **Единственное прерывание — RST 7 (VBlank)** на векторе 0x0038, ~50 Гц. Устанавливается в func_rom_init.

2. **ISR трёхфазный**: палитра/скроллинг → клавиатура → post-ISR (бордюр, скроллинг, состояние игры).

3. **Палитра**: 16 цветов из ROM-данных, записываются в порт 0x0C с NOP-задержками для тайминга.

4. **Записи в порт 0x03**: 8 записей с битовым сдвигом (0xFE→0x7F) в контексте сканирования клавиатуры. Скроллинг экрана в игре отсутствует — записи связаны с видеотаймингом или клавиатурным сканированием.

5. **Клавиатура в ISR**: 8 чтений Port B (0x02) с меняющимся скроллингом — сканирование матрицы клавиатуры.

6. **func_isr_game_state (0x3858)** — вызывается из ISR для обновления игрового состояния. Использует указатель из 0x3854 и переключатель 0x383A.

7. **RDB обновлён**: 61 объект (добавлено 6 новых: func_isr_game_state, var_isr_frame_count, var_border_color, var_isr_state_toggle, var_isr_data_ptr, var_isr_temp_ptr).
