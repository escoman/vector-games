# Карта токенов BASIC 2.997 (Вектор-06Ц) — токен ↔ ключевое слово ↔ обработчик

Рабочий чек-лист Stage 5. Декодируется из образа `src/basic.r0m` напрямую:
таблица ключевых слов `data_keyword_table` = `0x256E..0x26D6` (101 слово,
кодировка «байт на символ, bit7 = конец слова»), **токен = `0x80` + номер слова**.
Источники имён: собственные обработчики Stage 2 + официальные ключевые слова из
`Basic_Vector-06C.pdf` (Бейсик v2.5, Приложение 1 и §3 «Классификация»).

Сверка с документом (Приложение 1, коды внутреннего представления): из 89
слов документа **85 совпали** с таблицей ROM точно; `FOR`/`LLIST` в PDF —
OCR-ошибки (в ROM авторитетно `FOR=0x81`, `LLIST=0xDB`); `SPC(`/`TAB(` в ROM
хранятся со скобкой (`0x9F`/`0x9D`). Диапазон токенов ROM `0x80..0xE4` =
диапазон кодов документа. Авторитет при расхождении — всегда ROM.

Статус: `✓` — обработчик доказан и именован (Stage 2/3/5); `•` — адрес из
таблицы команд (Stage 5b), тело не вскрывалось; `(5d)` — подсистема.
Диспетчер команд закрыт в Stage 5a/5b.

## 1. Команды (операторы верхнего уровня), токены `0x80..0xAD` (слова 0..45)

Диспетчер команд вскрыт (Stage 5a/5b): **самомодифицируемый индексный переход**
(`func_cmd_dispatch` `0x049A`) по таблице адресов `data_cmd_table` `0x2700..0x276F`
(0x70 байт, 56 записей), смещение = (токен − 0x80)·2, записей плотные **два
сегмента**: операторы `0x80..0x9C` (off `0x00..0x38`) и расширения `0xCA..0xE4`
(off `0x3A..0x6E` через ветку `SUI 5A`); токены `0x9D..0xC9` отклоняются
(`JC 0074`) и слотов не занимают. Запись `0x0074` = «не оператор / нет аргумента».
(Не путать с диспетчером функций `0x0B09`/`0x2770`, покрывающим `0xAE..0xC9`.)
Статус обработчика: **✓** — тело подтверждено; **•** — адрес из таблицы (токен→
адрес доказан), тело не вскрыто; **(5d)** — подсистема ввода-вывода/графики/ленты.

## 3. Расширения, токены `0xCA..0xE4` (слова 74..100)

Вскрыты в Stage 5b: диспетчируются тем же `func_cmd_dispatch` по **второму
(плотному) сегменту** таблицы `data_cmd_table` (off `(2·token mod 256) − 0x5A` =
`0x3A..0x6E`). Функции/константы (`@`/ASN/ADDR/PI/ACS/LG) имеют заглушку `0x0074`
`(не вызываются как операторы; разбираются оценщиком). Статус: **✓** — тело
подтверждено; **•** — адрес из доказанной таблицы `data_cmd_table` + токен↔слово
Stage 2. Подсистемы (графика/звук/лента/печать/ВВ) именованы в Stage 5d
(`func_cmd_*`); PLOT/SCREEN/PAINT/CIRCLE/PLAY/CSAVE/OUT/POKE — тела подтверждены.

## 4. Как регенерировать

```
PYTHONPATH=utils python3 roms/redesign/basic/tools/dump_tokens.py  # токен ↔ слово из data_keyword_table
```

Таблица слов `0x256E`, 101 слово. При расширении RDB отмечать `•` как `✓`
(подтвердив тело) и обновлять адрес/имя обработчика. Имена `func_cmd_*` из
таблицы токен→адрес (Stage 5b) подтверждать по телу перед окончательным именованием.
