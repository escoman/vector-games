# Stage 4. Определение параметров функций

**ROM:** `./src/putup.rom`
**Метод:** Статический анализ кода + трассировка вызовов
**RDB объектов:** 55

## 1. Таблица параметров функций

### 1.1. ROM-функции (0x0100–0x07FF)

#### `func_rom_entry` — 0x0100
| | Описание |
|---|---|
| **Вход** | Нет (точка входа, вызов аппаратный) |
| **Выход** | Не возвращается (JMP 0x0B57) |
| **Модифицирует** | — (только DI) |
| **Стек** | Не использует |

#### `func_read_16bit_de` — 0x0104
| | Описание |
|---|---|
| **Вход** | HL = указатель на данные в ROM |
| **Выход** | DE = 16-бит значение; HL обновлён (+2) |
| **Модифицирует** | A, DE, HL |
| **Стек** | Не использует |
| **Побочный эффект** | Вызывает func_render_block 4 раза для отрисовки |

#### `func_sound_init` — 0x0121
| | Описание |
|---|---|
| **Вход** | Нет (параметры захардкожены) |
| **Выход** | Нет (A разрушается) |
| **Модифицирует** | A, E, HL (через dispatch) |
| **Стек** | Сохраняет D, PSW |
| **Побочный эффект** | Запись в порты ВИ53 (0x0B), очистка VRAM |

#### `func_data_loader2` — 0x0145
| | Описание |
|---|---|
| **Вход** | HL = указатель на данные; A = данные для отрисовки |
| **Выход** | HL обновлён (+1); [0x0B53] = новый указатель |
| **Модифицирует** | HL, A |
| **Стек** | Сохраняет H |
| **Побочный эффект** | Копирование в VRAM через func_copy_to_vram |

#### `func_store_data_ptr` — 0x014F
| | Описание |
|---|---|
| **Вход** | HL = значение для сохранения |
| **Выход** | Нет (HL не модифицируется) |
| **Модифицирует** | [0x0B53] (память) |
| **Стек** | Не использует |

#### `func_piece_type_lookup` — 0x0153
| | Описание |
|---|---|
| **Вход** | A = тип фигуры (1–7) |
| **Выход** | A = вариант отображения (0–7) |
| **Модифицирует** | A, D, E, HL (через вызовы) |
| **Стек** | Не использует |
| **Зависимости** | func_read_timer_data (псевдослучайный индекс) |

#### `func_keyboard_timer` — 0x017C
| | Описание |
|---|---|
| **Вход** | A = текущий кадровый счётчик (декрементируется); L = сравниваемое значение |
| **Выход** | A = результат (0 = клавиша нажата, ≠0 = не нажата/ожидание); флаг Z |
| **Модифицирует** | A, флаги |
| **Стек** | Не использует |
| **Побочный эффект** | IN 0x01 (чтение клавиатуры) каждые 7 кадров |

#### `func_read_timer_data` — 0x0197
| | Описание |
|---|---|
| **Вход** | Нет (адрес 0x08D3 захардкожен) |
| **Выход** | A = значение из таблицы таймера [0x08D3 + индекс] |
| **Модифицирует** | A, HL (через table_lookup) |
| **Стек** | Сохраняет H |

#### `func_data_loader` — 0x01A1
| | Описание |
|---|---|
| **Вход** | A = данные для отрисовки |
| **Выход** | HL обновлён; [0x0B53] = новый указатель |
| **Модифицирует** | A, HL |
| **Стек** | Не использует |
| **Побочный эффект** | Копирование в VRAM через func_copy_to_vram |

#### `func_set_stream_pos` — 0x01AE
| | Описание |
|---|---|
| **Вход** | Нет (адреса 0x08FE/0x08FF захардкожены) |
| **Выход** | [0x0B53] = 16-бит позиция из [0x08FE/FF] |
| **Модифицирует** | A, D, E, HL |
| **Стек** | Не использует |

#### `func_jmp_table_dispatch` — 0x01BC
| | Описание |
|---|---|
| **Вход** | A = индекс (маска ANI 0F, 0–15); E = параметр; B = сравнение (для CMP) |
| **Выход** | Зависит от индекса: запись в таблицу или вычисление mul7 |
| **Модифицирует** | A, HL, D (через PCHL) |
| **Стек** | Сохраняет H, D, PSW |
| **Побочный эффект** | PCHL — вычисленный переход |

#### `func_sound_timer_write` — 0x0201
| | Описание |
|---|---|
| **Вход** | Нет (адрес 0x031A захардкожен) |
| **Выход** | Нет |
| **Модифицирует** | A, HL |
| **Стек** | Не использует |
| **Побочный эффект** | OUT 0x0B (порт ВИ53) — 2 записи (младший + старший байт) |

#### `func_mul7` — 0x020E
| | Описание |
|---|---|
| **Вход** | HL = указатель на 16-бит значение в памяти |
| **Выход** | HL = значение × 12 |
| **Модифицирует** | HL, DE |
| **Стек** | Не использует |
| **Примечание** | Фактически умножает на 12, не на 7 (DAD-цепочка: ×2→DE=×2→×4→+DE=×6→×2=×12) |

#### `func_table_lookup` — 0x032C
| | Описание |
|---|---|
| **Вход** | HL = базовый адрес таблицы; A = индекс; B = 0 (для XRA B) |
| **Выход** | HL = HL + A (адрес элемента таблицы) |
| **Модифицирует** | HL, A, флаг переноса |
| **Стек** | Не использует |

#### `func_read_16bit_v2` — 0x0351
| | Описание |
|---|---|
| **Вход** | HL = указатель на 16-бит данные |
| **Выход** | DE = 16-бит значение; HL = HL + 2 |
| **Модифицирует** | DE, HL |
| **Стек** | Не использует |

#### `func_calc_vram_offset` — 0x0355
| | Описание |
|---|---|
| **Вход** | HL = делимое (16-бит); DE = делитель (16-бит) |
| **Выход** | A = частное; DE = остаток; HL = скорректированное значение |
| **Модифицирует** | A, C, DE, HL |
| **Стек** | Не использует |
| **Примечание** | 16-бит деление через повторное сложение с накоплением |

#### `func_rom_init` — 0x0383
| | Описание |
|---|---|
| **Вход** | Нет (все параметры захардкожены) |
| **Выход** | Нет |
| **Модифицирует** | A, HL |
| **Стек** | Не использует |
| **Побочный эффект** | OUT 0x10 (сброс банков); установка ISR вектора (0x0038→JMP 0x03A4); установка JMP 0x0B57 в 0x0000; EI |

#### `func_isr` — 0x03A4
| | Описание |
|---|---|
| **Вход** | Нет (аппаратное прерывание RST 7) |
| **Выход** | Нет |
| **Модифицирует** | Сохраняет/восстанавливает H, D, B, PSW |
| **Стек** | Сохраняет H, D, B, PSW (PUSH/POP) |
| **Побочный эффект** | OUT 0x0C (палитра, 16 цветов); OUT 0x03 (скроллинг); OUT 0x02; IN 0x02; инкремент [0x08DF] |

### 1.2. Функции распаковки (0x0400–0x0508)

#### `func_decompress` — 0x0400
| | Описание |
|---|---|
| **Вход** | Нет (все адреса захардкожены: источник 0x2761, цель 0x6000) |
| **Выход** | Нет |
| **Модифицирует** | Все регистры (сохраняет/восстанавливает H, D, B, PSW) |
| **Стек** | Сохраняет H, D, B, PSW; использует PUSH/POP для цикла |
| **Побочный эффект** | Запись 8192 байт в RAM (0x6000+): транспонирование + 4 битплэйн-декомпрессии |
| **Цикл** | 256 итераций × 4 плоскости × 8 байт |

#### `func_decomp_plane0` — 0x0439
| | Описание |
|---|---|
| **Вход** | DE = указатель на источник (убывающий); HL = указатель на приёмник |
| **Выход** | DE = DE − 8; HL = HL + 8; 8 байт распаковано |
| **Модифицирует** | A, B, C, DE, HL |
| **Стек** | Сохраняет B (счётчик) |
| **Биты** | 7 (битплэйн A) и 3 (битплэйн B) |

#### `func_decomp_plane1` — 0x045E
| | Описание |
|---|---|
| **Вход** | DE = указатель на источник; HL = указатель на приёмник |
| **Выход** | DE = DE − 8; HL = HL + 8 |
| **Модифицирует** | A, B, C, DE, HL |
| **Биты** | 6 и 2 |

#### `func_decomp_plane2` — 0x0483
| | Описание |
|---|---|
| **Вход** | DE = указатель на источник; HL = указатель на приёмник |
| **Выход** | DE = DE − 8; HL = HL + 8 |
| **Модифицирует** | A, B, C, DE, HL |
| **Биты** | 5 и 1 |

#### `func_decomp_plane3` — 0x04A8
| | Описание |
|---|---|
| **Вход** | DE = указатель на источник; HL = указатель на приёмник |
| **Выход** | DE = DE − 8; HL = HL + 8 |
| **Модифицирует** | A, B, C, DE, HL |
| **Биты** | 4 и 0 |

#### `func_decomp_transpose` — 0x04CD
| | Описание |
|---|---|
| **Вход** | Нет (HL=0x2761, BC=0x6000 захардкожены) |
| **Выход** | BC = обновлённый указатель приёмника; HL = обновлённый указатель источника |
| **Модифицирует** | A, BC, DE, HL |
| **Стек** | Использует PUSH для сохранения BC между блоками |
| **Объём** | 4 блока × 8 байт = 32 байт транcпонированных данных |

### 1.3. Распакованные функции (0x0800+)

#### `func_copy_to_vram` — 0x0800
| | Описание |
|---|---|
| **Вход** | A = данные для записи; HL = логический адрес экрана; BC = смещение |
| **Выход** | Данные записаны в VRAM; HL, BC модифицированы |
| **Модифицирует** | A, B, C, D, E, H, L |
| **Стек** | Сохраняет SP в 0x08DD (SP-swap трюк); DI/EI |
| **Побочный эффект** | Запись 16 байт в VRAM; чтение палитры из [0x08D0] |
| **Особенность** | Точка входа 0x0800 (ORA A; RZ — проверка A=0) и 0x0803 (основной код) |

#### `func_render_block` — 0x0803
| | Описание |
|---|---|
| **Вход** | A = данные; HL = логический адрес экрана; BC = смещение |
| **Выход** | Блок отрисован в VRAM |
| **Модифицирует** | Все регистры (сохраняет PSW, B, D, H) |
| **Стек** | Сохраняет PSW, B, D, H |
| **Побочный эффект** | Вызывает func_copy_to_vram |

#### `func_main_init` — 0x0B57
| | Описание |
|---|---|
| **Вход** | Нет (точка входа из JMP 0x0101) |
| **Выход** | Не возвращается (переход в игровой цикл) |
| **Модифицирует** | Все регистры |
| **Стек** | Устанавливает SP = 0x0100 |
| **Побочный эффект** | Очистка VRAM (0x8000–0xFFFF); очистка RAM (0x5000–0x53FF); инициализация переменных; вызов func_rom_init, func_decompress, func_sound_init; отображение заставки |

#### `func_piece_div2` — 0x0CA3
| | Описание |
|---|---|
| **Вход** | Нет (читает координаты из [0x08E9]) |
| **Выход** | [0x08FE/FF] = позиция; данные загружены через func_data_loader |
| **Модифицирует** | A, B, D, E, HL |
| **Стек** | Не использует |
| **Примечание** | Делит координаты на 16 (4× RAR), маска ANI 1F |

#### `func_game_loop` — 0x0CE0
| | Описание |
|---|---|
| **Вход** | Нет (читает состояние игры из 0x08E3+) |
| **Выход** | Не возвращается (цикл) |
| **Модифицирует** | Все регистры |
| **Стек** | Использует для вызовов |
| **Побочный эффект** | Опрос клавиатуры; отрисовка фигур; очистка рядов |

#### `func_vram_clear` — 0x0EF7
| | Описание |
|---|---|
| **Вход** | B = счётчик итераций (определяет объём очистки); HL = начальный адрес |
| **Выход** | Область VRAM обнулена |
| **Модифицирует** | A, B, HL |
| **Стек** | Сохраняет H, PSW |

## 4. Паттерны вызовов

### 4.1. Типичные параметры при вызове

**func_render_block / func_copy_to_vram:**
```asm
MVI A, data_byte    ; данные для записи
LXI H, screen_addr  ; логический адрес экрана
LXI B, offset       ; смещение
CALL 0x0803         ; render_block
```

**func_jmp_table_dispatch:**
```asm
MVI E, param        ; параметр для записи
MVI A, index        ; индекс 0-15 (ANI 0F)
CALL 0x01BC         ; dispatch
```

**func_keyboard_timer:**
```asm
LDA counter         ; загрузить счётчик
; A = счётчик
; L = сравниваемое значение
CALL 0x017C         ; keyboard_timer
; A = результат, Z = флаг
```

**func_decomp_plane0-3:**
```asm
; DE = источник (убывающий)
; HL = приёмник (возрастающий)
CALL 0x0439         ; plane0 (биты 7,3)
; DE -= 8, HL += 8
```

### 4.2. Функции без параметров (самодостаточные)

Эти функции не требуют предварительной настройки регистров:
- `func_sound_init` — все параметры захардкожены
- `func_rom_init` — все параметры захардкожены
- `func_decompress` — адреса 0x2761→0x6000 захардкожены
- `func_main_init` — точка входа, SP=0x0100
- `func_isr` — аппаратное прерывание
- `func_game_loop` — читает состояние из памяти

## 5. Ключевые выводы

1. **Большинство ROM-функций (12 из 32) не имеют входных параметров** — все адреса и данные захардкожены. Это типично для ROM с фиксированной структурой данных.

2. **8 функций принимают параметры через регистры** — основной паттерн: A = данные, HL = адрес, DE = значение.

3. **func_mul7 умножает на 12, а не на 7** — подтверждено анализом DAD-цепочки.

4. **func_decomp_plane0-3 имеют идентичную структуру** — отличаются только масками битов (80/08, 40/04, 20/02, 10/01).

5. **func_copy_to_vram имеет две точки входа**: 0x0800 (с проверкой A=0) и 0x0803 (основной код).

6. **func_isr сохраняет все регистры** (H, D, B, PSW) — стандартная практика для ISR.

7. **func_render_block и func_copy_to_vram — самые «дорогие» по регистрам** — модифицируют все 7 регистров общего назначения.
