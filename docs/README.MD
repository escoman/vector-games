# Документация (docs/)

Технические справочники по «Вектору-06Ц» (КР580ВМ80A / i8080) и тулчейну
z88dk. Это источник истины для написания корректного ассемблерного и машинного
кода, а также для портирования C через z88dk.

## Устройство Вектора-06Ц

| Файл | О чём |
|------|-------|
| [VECTOR.MD](VECTOR.MD) | Полная документация по процессору, ASM и машинному коду: память, порты, прерывания, видеорежимы. Основной справочник проекта. |
| [VECTOR_VERIFIED.md](VECTOR_VERIFIED.md) | Результаты полного фактологического аудита — только проверенные сведения (основана на «Секретах Вектора» А. З. Лебедева, эмуляторах и таймингах). |
| [VECTOR_CPU_COMMANDS.md](VECTOR_CPU_COMMANDS.md) | Система команд КР580ВМ80A (отечественный аналог Intel 8080A): все инструкции, байт-коды, флаги, такты. |
| [512x256.MD](512x256.MD) | Отдельная инструкция по графическому режиму 512×256: адресация VRAM, плоскости, палитра, вывод. |
| [vector_techinfo.md](vector_techinfo.md) | Внешняя техинформация по ПК «Вектор» (источник: EMU80, А. Тимошенко / TIMSoft). |

## Тулчейн z88dk

| Файл | О чём |
|------|-------|
| [Z88DK.md](Z88DK.md) | Разбор библиотеки z88dk: target `vector06c` (сборка как 8080), структура репозитория и `include/`. |
| [Z88DK_CALL.md](Z88DK_CALL.md) | Соглашения о вызовах C ↔ ASM: три конвенции z88dk, `__z88dk_callee`, доступ к стековым параметрам. |
| [Z88DK_512_SOUND.md](Z88DK_512_SOUND.md) | Исследование поддержки z88dk для режима 512×256 и звука (что готово, а что нет). |

## Как связано с кодом

- Реализация описанных здесь портов и режимов — в [`../lib`](../lib)
  (см. [lib/README.md](../lib/README.md) и схему `lib/scheme.jpg`).
- Готовые ROM и их документация — в [`../roms`](../roms).
- Скрипты конвертации ассетов — в [`../utils`](../utils).
