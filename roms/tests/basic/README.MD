# basic — вывод текста шрифтом BASIC (Вектор-06Ц)

Минимальный пример: печатает строки **шрифтом BASIC 2.997** (5×8, хранится
СТОЛБЦАМИ) с точностью до пикселя по горизонтали. Алгоритм восстановлен из
живого интерпретатора и воспроизведён бит-в-бит.

## Что демонстрирует

Шрифт BASIC хранится вертикальными колонками (байт = колонка, `bit0` = верх),
а кадр Вектора — горизонтальными байтами (1 байт = 8 пикселей по X, бит7 =
левый). Между ними нужен **поворот на 90°**. Побочный, но главный эффект:
горизонтальное позиционирование становится **попиксельным** — глиф встаёт на
любой X, а не только кратный 8 (ячейка BASIC — 6 px, не кратна байту).

На экране:

* заголовок и панграмма (режим шага ячейки 6 px, как в терминале BASIC);
* сетка всех глифов `0x20..0x7F`;
* **полоса фаз 0..7** — одно слово, сдвинутое на каждый битовый сдвиг внутри
  байта: видно, что глиф корректно ложится в любой пиксельный X;
* переключатель шага `CELL=6` (BASIC, глифы слегка наезжают) / `CELL=8`
  (выровнено по байту).

## Управление

* `ТАБ` — переключить шаг ячейки 6 px ↔ 8 px;
* `АП2` (ESC) — выход.

## Сборка

```
make            # basic.rom
make full       # clean + all + deploy в ROMS эмулятора
```

Шрифт (`basic_font.asm`) — сгенерированный файл, лежит в репозитории.
Перегенерировать (читает 640 байт из `roms/redesign/basic/src/basic_new.r0m`
по адресу `0x379F`):

```
python3 tools/gen_font.py
```

## Как восстановлен алгоритм

* `roms/redesign/basic/tools/trace_glyph.py` — печатает `TIV` на READY
  эталонного BASIC и по diff VRAM показывает, в какие байты/биты/пиксели
  раскладываются биты колонок (подтверждает transpose, шаг +6 px, `bit0`=верх,
  запись во все 4 плоскости).
* Запись алгоритма — `roms/redesign/basic/reports/Stage7.md` §8.
