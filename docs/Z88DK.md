# Соглашения о вызовах z88dk (C ↔ ASM)

## Три соглашения о вызовах

В z88dk существуют три соглашения:

### 1. Стандартное C (`__smallc`)

Используется по умолчанию для `extern`-объявлений.

**CALLER:**
1. Пушит аргументы **слева направо** (первый аргумент первым!)
2. `call func`
3. Чистит стек (`pop` после возврата)
4. Возвращаемое значение в подмножестве DEHL

**CALLEE:**
1. Стек выше адреса возврата не трогать (caller почистит)
2. Доступ к параметрам через pop/push-последовательность
3. Возврат в DEHL

> **Важно:** z88dk (sccz80) пушит аргументы СПРАВА НАЛЕВО для `__callee`
> и СЛЕВА НАПРАВО для стандартного C. Это отличается от документации!

### 2. Fastcall (`__z88dk_fastcall`)

Один параметр передаётся через регистр DEHL.

**CALLER:**
1. Загрузить DEHL значением аргумента (L — 8 бит, HL — 16 бит, DEHL — 32 бита)
2. `call func`
3. Возврат в DEHL

**CALLEE:**
1. Аргумент уже в DEHL
2. Возврат в DEHL

```c
extern unsigned char foo(unsigned int a) __z88dk_fastcall;
```

```asm
PUBLIC _foo
_foo:
    ; HL = параметр a
    ld l, 0       ; возвращаемое значение
    ret
```

### 3. Callee (`__z88dk_callee`)

Callee читает параметры и чистит стек. **Предпочтительно для ASM-функций.**

**CALLER:**
1. Пушит аргументы **слева направо**
2. `call func`
3. НЕ чистит стек
4. Возврат в DEHL

**CALLEE:**
1. Pop параметры со стека
2. Восстановить адрес возврата
3. Возврат в DEHL

```c
extern void write_tile(unsigned int addr, const unsigned char *src) __z88dk_callee;
```

```asm
PUBLIC _write_tile
_write_tile:
    pop hl          ; HL = адрес возврата
    pop de          ; DE = src  (второй аргумент, наверху стека)
    pop bc          ; BC = addr (первый аргумент)
    push hl         ; адрес возврата обратно — стек чист

    ; BC = addr, DE = src
    ld h, b
    ld l, c         ; HL = addr (VRAM)
    ld b, 8         ; счётчик
wt_loop:
    ld a, (de)
    ld (hl), a
    inc de
    dec l
    dec b
    jp nz, wt_loop
    ret
```

## Порядок аргументов на стеке

z88dk пушит аргументы **слева направо** (первый аргумент пушится первым,
оказывается ниже на стеке):

```
push addr       ; первый аргумент (ниже)
push src        ; второй аргумент (выше, наверху)
call func
```

Стек при входе в функцию:
```
SP+0: адрес возврата
SP+2: первый аргумент  (addr)
SP+4: второй аргумент  (src)
```

При pop: первый pop = второй аргумент (src), второй pop = первый аргумент (addr).

## Сохранение регистров

- **Callee-saved:** BC (должна сохраняться callee)
- **Caller-saved:** AF, DE, HL
- Возвращаемое значение: L (8 бит), HL (16 бит), DEHL (32 бита)

## Рекомендации

- Для ASM-подпрограмм всегда использовать `__z88dk_callee` или `__z88dk_fastcall`
- `__z88dk_callee` эффективнее стандартного C: нет лишнего `pop bc; pop bc` у caller
- `__z88dk_fastcall` ещё эффективнее для одного аргумента: нет push/pop вообще
- Стандартное C — только для функций с переменным числом аргументов (printf)
  или указателей на функции
