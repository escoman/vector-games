Пишем ROM для Вектора-06Ц в папке music-roms/jackal. ROM является музыкальной программой, которая воспроизводит саундтрек из игры Jackal (NES).

Треки (клавиша в меню): 1 — Intro, 2 — Level 1, 3 — Level 2, 4 — Level 3, 5 — Boss, 6 — Final Boss, 7 — Stage Clear, 8 — Game Over, 9 — Ending, 0 — стоп, СТОП (ESC) — выход. Уровни и боссы зациклены, джинглы играют один раз.
