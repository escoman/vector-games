# clrs — тест смены палитры по лучу

![clrs](screen.png)

Тестовый ROM: демонстрация записи в регистр палитры (порт `0x0C`) прямо во
время развёртки — «гонка за электролучом». Каждая горизонтальная полоса
получает свой цвет, потому что палитра меняется между строками кадра. На
экране — сетка градиентов по строкам и столбцам.

Реализация целиком на ассемблере (`clrs.asm`), синхронизация с лучом по
вертикальному гасящему импульсу.

## Сборка

```bash
make          # собрать clrs.rom
make deploy   # собрать + положить в ROMS эмулятора PPSSPP
make full     # clean + deploy
```

Тот же эффект в восстановленной оригинальной ROM —
[`../../redesign/clrs`](../../redesign/clrs).
