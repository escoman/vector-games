# Stage 9 — Консолидированный ASM → `asm/` (ветвь A: монолит, byte-identical)

ТЗ §9: собрать выход разбора (код + данные) в **единое** дерево `asm/`, не
дробя на «файл/блоб на функцию», и **явно зафиксировать развилку** A/B. Итог:
выбрана **ветвь A** — один адресно-упорядоченный `code.asm` под общим `ORG`,
собирается **побайтово** в `src/basic.r0m` (0 расхождений, 17152 байт).
Инструмент-источник: `tools/stage9_asm_layout.py`.

---

## 0. Развилка и её выбор

| ветвь | раскладка | round-trip | выбрана |
|---|---|---|---|
| **A. Монолит** | `basic_new.asm` (ORG 0000h) + `code.asm` (весь адресный поток) | **byte-for-byte** в `basic.r0m` | **ДА** |
| B. Файлы-классы | каждый класс на своём `ORG` | функционально-эквивалентно, НЕ побайтово | нет |

**Почему A.** Page-zero (`0x0000..00FF`) — служебные ячейки на фиксированных
адресах, двигать нельзя. Интерпретатор адресно-зависим: само-ссылочные
`JMP/CALL/LXI` зашиты литералами, а код и таблицы перемешаны. Побайтовый
round-trip — сквозной контракт всего разбора. Релокация (B) потребовала бы
аудита всех само-ссылок и подмены литералов метками — это **Stage 11**, не здесь.

## 1. Дерево `asm/`

```
asm/
├── basic_new.asm   мастер компоновки: ORG 00000h + include equates + include code
├── code.asm        адресный монолит 0x0000..0x42FF (код мнемониками + DEFB-данные)
├── equates.asm     аппаратные EQU (порты PIA/ВИ53/палитра/банки, плоскости VRAM,
│                   вершина стека, базы знакоместа/таблиц) — источник: VECTOR_VERIFIED.md
├── glyphs.inc      ┐ read-only человеческие просмотры (Stage 7/8),
├── keywords.inc    │ в сборку НЕ входят, чтобы не дублировать DEFB
├── messages.inc    │
└── demo.inc        ┘
```

Артефакты сборки `basic_new.bin` / `.o` / `.sym` — в `.gitignore`.

**Принцип «не дробить».** Один класс — один файл. `code.asm` несёт и код, и
ROM-backed данные (`data_keyword_table`, `data_error_messages`,
`data_glyph_block`, `str_autoload`, `data_cmd/dispatch_table`,
`data_irq_palette_table`) как `DEFB` по меткам RDB — ровно по одному байту на
каждый адрес окна. RAM-backed (`var_*`, runtime-буферы, векторы) — это метки в
адресном потоке, байт не эмитят.

## 2. Что внутри `code.asm` (сводка экспорта)

Из `export.json` (тот же источник, что и `layout.asm`):

* объект RDB: **554**, связей **147**;
* диапазон кода: **47** сегментов, **12705** байт, **7240** инструкций;
* диапазон данных: **17** регионов, **1485** байт;
* гэпы (ни код, ни объект) эмитятся как `gap_xxxx: DEFB …` — окно закрыто
  полностью, поэтому сборка даёт точный размер 17152 байта.

`code.asm` — дословный `layout.asm` пайплайновой стадии `export_asm`
(v06c-asm-export), дополненный шапкой. Ручное редактирование не нужно:
источник истины — RDB + инструменты Stage 7/8.

## 3. `equates.asm` — аппаратная карта (проверено)

Только `EQU` (байт не эмитит → включение до `code.asm` не сдвигает адреса).
Имена подобраны так, чтобы не пересекаться с метками `code.asm`
(`func_*`/`lbl_*`/`var_*`/`data_*`/`gap_*`); инструмент пропускает коллизии.

| группа | символы |
|---|---|
| PIA КР580ВВ55 | `PORT_PIA_CW` 00h, `PORT_PIA_PC` 01h, `PORT_PIA_PB` 02h, `PORT_PIA_PA` 03h |
| КР580ВИ53 (таймер/звук) | `PORT_VI53_CW` 08h, `PORT_VI53_C2` 09h, `PORT_VI53_C1` 0Ah, `PORT_VI53_C0` 0Bh |
| палитра | `PORT_PALETTE` 0Ch (+ зеркала 0Dh..0Fh) |
| банки | `PORT_BANK` 10h |
| VRAM-плоскости | `PLANE3_BASE` 8000h, `PLANE2_BASE` 0A000h, `PLANE1_BASE` 0C000h, `PLANE0_BASE` 0E000h |
| boot/структуры | `STACK_TOP` 7FFFh, `GLYPH_BASE` 379Fh, `KEYWORD_BASE` 256Eh, `MSGPOOL_BASE` 2465h, `AUTOLOAD_BASE` 4012h, `RAM_IMAGE_SIZE` 4300h |

Фактические порты подтверждены разбором `IN/OUT` в `code.asm`: используются
00h,01h,02h,03h,04h,05h,07h,08h,09h,0Ch — все покрыты картой.

## 4. Сборка и приёмка

```
z80asm -b -m=8080_strict basic_new.asm -o=basic_new.bin   # из каталога asm/
cmp basic_new.bin src/basic.r0m                            # → 0 расхождений
```

* сборка: **успех**, `basic_new.bin` = **17152 байт**;
* round-trip: **BYTE-FOR-BYTE OK** (17152/17152, расхождений **0**);
* пайплайн `run_pipeline.sh basic --from export_asm`: **6/6 SUCCESS**;
* RDB: **554 объекта**, `dirty: False`.

`tools/stage9_asm_layout.py` прогоняет всё одной командой: `--check` (план) /
`--apply` (сгенерировать `asm/`, собрать, сверить; ненулевой код возврата при
расхождении).
