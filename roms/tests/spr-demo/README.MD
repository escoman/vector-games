# spr-demo — проверка стандартных ядер спрайтов

Отдельное приложение, проверяющее работоспособность библиотечных ядер
вывода спрайтов [lib/gfx/spr.asm](../../../lib/gfx/spr.asm) — пара методов
`spr_init` / `spr_blit` / `spr_blit_mask` (спека формата — [docs/SPR_FORMAT.MD](../../../docs/SPR_FORMAT.MD)).
В отличие от [spr-speed](../spr-speed), который является полигоном для
обкатки алгоритмов, этот ROM — чистый потребитель библиотеки: никаких
локальных копий ядер, только `#include "v06.h"` и линковка `spr.asm`.

## Что показывает

Экран 256×256×16, палитра mario-dbl (0=голубой, 1=красный, 2=розовый,
3=чёрный). Один и тот же спрайт-«инопланетянин» 24×24 (3 столбца,
плоскости П1+П0, 3 фазы анимации) выводится двумя способами:

* **Верхняя полоса (шахматка в П0) — `spr_blit_mask`**: OR-композит
  `dst = (dst AND mask) OR color`. Маска прошлые позиции не стирает,
  поэтому шахматка перерисовывается каждый кадр (как `fill_checker`
  в spr-speed), а прорезь рта показывает её насквозь. Отдельный erase
  не нужен.
* **Нижняя полоса (вертикальные полоски в П1) — `spr_blit`**: плоская
  запись. Каждый кадр прошлая позиция затирается дескриптором-ящиком
  `inv_erase`, затем спрайт рисуется на новом месте. Ящик пишет нули,
  поэтому в полосатом фоне за спрайтом остаются прорехи — видно, что
  плоский блит фон не сохраняет.

## Файлы

| Файл | Назначение |
|------|------------|
| `main.c` | Сцена, цикл анимации, `gfx_next_frame()` (HALT до VBlank) |
| `spr.inc` | Данные спрайтов SPR_FORMAT (сгенерирован, не править руками) |
| `gen_spr.py` | Генератор `spr.inc`: арт рисуется кругами/прямоугольниками |
| `Makefile` | `make full` — clean + сборка + deploy в эмулятор |

Перегенерировать данные: `python3 gen_spr.py`.

## Сборка и проверка

```sh
make full        # clean + build + deploy (PPSSPP-эмулятор)
```

После старта в эмуляторе:

1. `spr_init()` собирает «лесенки» в ОЗУ (0x7000..0x7081 — копирование,
   0x7100..0x7203 — композиция) — куча не должна дорастать до 0x7000.
2. Верхний спрайт ходит по шахматке: фон под ним каждый кадр
   восстанавливается, клетки целые, в прорези рта видна шахматка.
3. Нижний спрайт ходит по полоскам со стиранием — за ним остаётся
   полоса прорех в фоне.
4. Ограничения формата соблюдены: LEN ≤ 28 (маска), ≤ 32 (плоский),
   x кратен 8.
