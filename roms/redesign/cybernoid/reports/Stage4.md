# Stage 4. Прерывания и тикер речи (cyberno.rom)

## Постановка (TZ §Stage 4)

Векторы `0x0008…0x0020` (RST 0/8/16/24), `0x0038` (RST 7 / VBlank), `0x003C`
INTERPT. Ключевой вопрос: **чем тарифицируется речь** — ISR VBlank, таймер
ВИ53 или busy-loop внутри речевого движка. Ответ — в RDB (`func_irq_*`,
свойство «шаг»), здесь — краткий обзор.

## Метод

Только live-данные через `vector-debugger` MCP: `debug_get_int_events`
(ret_pc/was_halt/beam на каждом INT), `debug_get_io_trace` (последние 10 000
событий), `debug_disassemble_range` (векторная страница и exec-адреса),
`debug_get_beam_state`, точки останова на входе речи (exec 0x0663) и на
первом `OUT 00` эмита (exec 0x0704). Побайтовая проверка ROM-файла на `EI`
(0xFB) — скрипт по файлу, без декодирования.

## Факты

1. **Прошит только один вектор.** После boot: `0x0000: JMP 0100`,
   `0x0038: JMP 0E00`; `0x0008…0x0037` — NOP (RST 0/8/16/24 не используются,
   `0x003C` INTERPT не задействован). Подтверждено `debug_disassemble_range`
   по живой памяти.
2. **ISR = RAM-резидентный стаб на 0x0E00.** `int_events`: ровно
   **1 прерывание на кадр** (729 событий / 729 кадров), всегда vector
   `0x0038`, `raster_line=0`, `v_cycle_in_line≈188–236`. Тело (exec-дамп):
   PUSH PSW/B/D/H → sweep луча (`OUT 02` + 6×`OUT 0C` из таблицы 0x0E71) →
   `OUT 00,8A` → гонка `IN 02/CPI FF` c `OUT 03` → `CALL 0E57`
   (`OUT 00,88`) → POP → `EI; RET`. **Важно:** в ROM-файле по 0x0E00 —
   данные; код появляется после распаковки (тот же паттерн файл≠exec, что и
   речевой блок −0x59). Stage-2 ярлык `label_blob_0E00` («НЕ ФУНКЦИЯ»)
   снят — объект переименован в `func_irq_vblank_isr`.
3. **Простой — HLT.** Последние кадры idle: `was_halt=true`,
   `ret_pc=0x0F3D` каждый кадр; `HLT` подтверждён на **0x0F3C** (живой дамп),
   сразу за EI-хвостом blob 0x0DD0 (file 0x0F2A/0x0F3E). То есть кадр =
   VBlank-пробуждение, а не кружение.
4. **Речь — busy-loop при IFF=0 (ответ на главный вопрос).**
   - Вход речи (exec 0x0663) = `DI`; живая остановка на первом `OUT 00`
     эмита (exec 0x0704) — **iff=false**; случайные пики во время фраз —
     PC внутри речевого диапазона.
   - Во всём ROM-файле на участках речевой цепочки (0x06BC…0x0790) и вызывающего
     блока (0x0573…0x0600) **нет ни одного байта 0xFB (EI)** — ISR физически не
     может тикать синтез; EI возвращается хвостом блока 0x0DD0 (0x0F2A/0x0F3E).
   - Шаг бита — **софтверный счётчик**: `LDA 0733 / DCR A / JNZ`
     (exec 0x0706–0x070C; паттерн `3A 33 07 3D C2 09 07` найден в файле на
     0x078C). Никаких обращений к таймеру/лучу в цикле эмита.
5. **ВИ53 (порты 08h–0Bh) в речи не участвует.** `io_trace` (10 000 событий,
   ~76 кадров): 0 обращений к 08–0B. Ставит под вопрос классификацию
   `func_vi53_timer_poll@0x0F9A` (тело читает RAM 10AD/10B0/10B2) —
   помечено свойством `stage4_note`, пересмотр в Stage 5/7.
6. **Очередь фраз.** Речевой вызов — блокирующий, «одна фраза за вызов»:
   exec 0x0579 `LXI H,0600; CALL 0660`, затем exec 0x05E1–0x05E9
   `CALL 0660; MVI A,00; STA 0600; JMP 0DD0` — буфер 0x0600 очищается после
   произнесения. Живая остановка на входе речи: HL=0x09C3 → таблица фраз
   `ODIN\0 DWA\0 TRI\0 «DIL SOFT PR…»` (числительные меню).

## Итог в RDB

- `func_irq_vblank_isr` @0x0E00 (Function, size 71): комментарий +
  `interrupt_vector`, `tick_rate`, `isr_io_ports`, `source`; links → 0x0F3D,
  0x06BC.
- `label_idle_hlt` @0x0F3D (новая): HLT-сон до VBlank (was_halt-доказательство).
- `func_speak_start` @0x06BC: `speech_metering` (busy-loop, DI, ни одного EI),
  `speech_step` (счётчик LDA 0733; ВИ53/IN 02 не используются); link → 0x0E00.
- `func_speak_walker` @0x06C2: `phrase_queue` (буфер 0x0600, очистка STA 0600).
- `label_blob_0DD0`: `ei_tail` (EI на 0x0F2A/0x0F3E).
- `func_vi53_timer_poll` @0x0F9A: `stage4_note` (ноль портов 08–0B в трассе).
Сохранено `debug_save_rdb`; круговой контроль по файлу `.rdb` пройден.

## Ограничения и открытые вопросы

- Период бита PDM в этом прогоне не замерялся циклово (буфер io_trace
  отсёк burst до останова); оценка задержки `LDA 0733`-счётчиком — из кода,
  точное значение счётчика и его самонастройка (INR M рядом с 0x0745) —
  Stage 7.
- Кто и откуда распаковывает стаб ISR (0x0E00) — механизм архива, как и
  −0x59 речи, — Stage 7.
- `func_vi53_timer_poll` — вероятная мисклассификация Stage 2; используется
  ли ВИ53 вообще (звук меню?) — проверить трассой в игровых состояниях.
- Речь в трассе ловилась клавишами меню («1», SPACE, ENTER); полный маршрут
  экранов — Stage 5.
