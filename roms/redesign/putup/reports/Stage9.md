# Stage 9. Поиск и исследование карт уровней

## Ход исследования

### Шаг 1-2. Код после нажатия пробела

В `func_main_init` найден цикл ожидания пробела на заставке (`lbl_title_key_poll` @ 0x0C65).
После нажатия пробела выполняется:
```
CALL func_sound_hw_init   ; 0x0C9D — инициализация звука
JMP func_level_init       ; 0x0CA0 — инициализация уровня
```

### Шаг 3. Функция рисования уровня

Функция `func_level_init` @ 0x197C выполняет:
1. Инкремент счётчика уровней в ячейке 0x08F5
2. Копирование 8 байт метаданных текущего уровня в RAM (0911-0918)
3. Вычисление адреса карты уровня
4. Цикл обхода 176 байт карты с отрисовкой тайлов

### Шаг 4. Вычисление адреса карты и координаты

**Метаданные** (8 байт на уровень):
```
LXI H, 1C0E           ; базовый адрес таблицы метаданных
LDA 08F5              ; номер уровня
RLC × 3               ; × 8 (размер записи)
MOV E, A; MVI D, 0
DAD D                 ; HL = 1C0E + level*8
LXI B, 0008           ; 8 байт для копирования
CALL 1BC9             ; копирование в 0911-0918
```

**Карта** (176 байт на уровень):
```
LXI H, 1C8E           ; базовый адрес таблиц карт
LDA 08F5; DCR A       ; номер уровня - 1
; цикл: HL += 0x00B0 (176) для каждого уровня
LXI B, 00B0           ; 176 байт = 16×11
; цикл отрисовки тайлов
```

### Шаг 5-6. Структура данных уровней

#### Таблица метаданных @ 0x1C0E (15 × 8 = 120 байт)

| +5 | Координата Y врага 1 |
| +6 | Координата X врага 2 |
| +7 | Координата Y врага 2 |

## Объекты RDB

Созданы объекты:
- `data_level_metadata` @ 0x1C0E, size=120, type=Table — таблица метаданных 15 уровней
- `data_level_maps` @ 0x1C8E, size=2640, type=Table — таблица карт 15 уровней
- `data_level_02` .. `data_level_15` — отдельные карты уровней (data_level_01 совпадает с data_level_maps)

## Общие данные

- Общий блок данных уровней: 0x1C0E — 0x26DD (2768 байт)
- Метаданные: 0x1C0E — 0x1C8D (120 байт)
- Карты: 0x1C8E — 0x26DD (2640 байт)
