# Stage 9a (опционально) — Звук/музыка интерпретатора → MID: **N/A**

Условие выполнения (ТЗ §9a): **(а)** в демо-программе есть мелодия **и**
**(б)** драйвер звука активен (ячейки `772..775`, VBlank-тик). Требуется
подтвердить **оба** пункта. В этом ROM не подтверждён ни один → стадия **N/A**.

## Обоснование

* **Демо-программы нет.** Спека v2.5 указывала «демо @ `0x3C60`», но по
  `0x3C60` лежит **код**, а не BASIC-листинг (проверено на Stage 8). Единственный
  автозапуск — `str_autoload` @ `0x4012` = `COLOR15,0,1:CLS` (16 байт): только
  палитра и очистка экрана, **ни `PLAY`, ни `BEEP`, ни нот**. Мелодии нет.
* **Драйвер звука не активен на boot.** Интерпретатор содержит рутины звука
  (`PLAY`/`BEEP`, счётчики КР580ВИ53 `09h..0Bh`), но они вызываются явно
  пользователем из программы. Автозапуск их не дёргает, VBlank-тик мелодию не
  проигрывает (играть нечего). Ячейки `772..775` в boot-пути не инициализируются
  как музыкальный курсор.

## Итог

Нет входных данных для `tools/music_spec.json` / `music2midi` → `basic_demo.mid`
не создаётся. Стадия закрыта как **N/A** с настоящим обоснованием. Реальный
звук Вектора-06Ц (AY-3-8910 / ВИ53) разобран в других ROM проекта
(`roms/musics/*`), к BASIC 2.997 отношения не имеет.
