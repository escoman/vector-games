# testay — реверс-инжиниринг `TESTAY.ROM` (плеер AY-3-8910)

![testay](screen.png)

Восстановление исходников оригинальной ROM **TESTAY.ROM** — автономного
плеера музыки на звуковом чипе **AY-3-8910** для «Вектора-06Ц». Чистый i8080,
3712 байта, загружается по адресу `0x0100`.

> **Графики нет:** видеопланы намеренно не заполняются (область `0xC2xx`
> используется только как стек). Единственный «выход» программы — звук в порты
> `0x15`/`0x14`. Поэтому снимок экрана чёрный — это корректное поведение ROM.

Компактный секвенсор-интерпретатор: нотные потоки лежат в памяти в
зашифрованном (XOR) виде, на каждом тике расширяются и превращаются в значения
регистров AY.

## Результат

- `src/TESTAY_NEW.ROM` — пересобранная ROM с переносом стека на `0x8000`;
- описание алгоритма — [reports/Algorithm.md](reports/Algorithm.md);
- этапы — [reports/](reports/) (Stage1…Stage3), постановка — [TZ.md](TZ.md);
- выгруженная музыка — `testay.mid`.
