# check_bugs — регресс-тест багов стека

![check_bugs](screen.png)

Минимальный тест для проверки корректности вызовов ASM-процедур из C
(очистка экрана, загрузка палитры, рисование по плоскостям) — с намеренно
воспроизведённым PUSH-багом в `plane_fill`. Служит изолированным стендом:
проверяет баланс стека и сохранность регистров на стыке C ↔ ассемблер.

На экране — маленький цветной блок (результат заполнения плоскости), остальной
фон чёрный.

## Сборка

```bash
make          # собрать check_bugs.rom
make deploy   # собрать + положить в ROMS эмулятора PPSSPP
make full     # clean + deploy
```
