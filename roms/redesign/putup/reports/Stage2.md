# Stage 2. Первичное обследование функций и блоков данных

**ROM:** `./src/putup.rom`
**Метод:** Дизассемблирование ROM (0x0100–0x07FF) + анализ распакованного кода (0x0800+)
**Состояние:** Заставка игры, ожидание SPACE (PC = 0x0C6A)
**RDB объектов:** 50

---

## 1. Структура ROM-кода (0x0100–0x07FF)

### 1.1. Точка входа и инициализация

| Адрес | Имя | Размер | Описание |
|-------|-----|--------|----------|
| 0x0100 | `func_rom_entry` | 4 | DI; JMP 0x0B57 — вход в ROM |
| 0x0383 | `func_rom_init` | 33 | Инициализация PIA (порт 0x10), таймеров, ISR-вектора (0x0038→ISR), JMP 0x0B57 в 0x0000, EI |
| 0x03A4 | `func_isr` | — | ISR: сохранение регистров, инкремент счётчика кадров 0x08DF, восстановление |

### 1.2. Работа с данными

| Адрес | Имя | Размер | Описание |
|-------|-----|--------|----------|
| 0x010C | `func_read_16bit_de` | 16 | Читает 16-бит из [HL] в DE через CALL 0x1BD4, затем 4× вызов 0x0803 |
| 0x0145 | `func_data_loader2` | — | CALL 0x0800 (block_copy), INX H, SHLD 0x0B53 — простая загрузка данных |
| 0x014F | `func_set_data_ptr` | 4 | SHLD 0x0B53; RET — установка указателя данных |
| 0x01A1 | `func_data_loader` | 13 | Читает указатель из [0x0B53], вызывает 0x0800, инкрементирует указатель |
| 0x01AE | `func_set_data_pos` | 12 | Читает из 0x08FE/0x08FF, вызывает 0x1BD4, JMP 0x014F |
| 0x0331 | `func_read_16bit` | 4 | Читает 16-бит из [HL] в DE (аналог func_read_16bit_de) |
| 0x0355 | `func_16bit_division` | 15 | 16-бит деление/вычисление через повторное вычитание (DAD D цикл) |
| 0x032C | `func_table_lookup` | 20 | Табличный индекс: XRA B, MOV L,A; RNC/INR H для переноса |

### 1.3. Клавиатура и таймер

| Адрес | Имя | Размер | Описание |
|-------|-----|--------|----------|
| 0x017C | `func_keyboard_timer` | 30 | Опрос клавиатуры (IN 0x01, ANI 0x20 = SPACE) + кадровый таймер (7-тактный цикл) |
| 0x0197 | `func_read_timer_data` | 10 | Чтение данных таймера из таблицы 0x08D3 |

### 1.4. Звук / таймер ВИ53

| Адрес | Имя | Размер | Описание |
|-------|-----|--------|----------|
| 0x0121 | `func_sound_init` | — | Инициализация звука: 4× вызов диспетчера (0x01BC) + очистка VRAM (0x0EF7) |
| 0x01BC | `func_jmp_table_dispatch` | 24 | Диспетчер: ANI 0F, таблица 0x01CD, PCHL (вычисленный переход) |
| 0x01CD | `data_jmp_table` | 32 | Таблица переходов: 16 записей × 2 байта (адреса подпрограмм) |
| 0x0201 | `func_sound_timer_write` | 13 | Запись в ВИ53: читает 16-бит из 0x031A, ×7, OUT 0x0B |
| 0x020E | `func_mul7` | 11 | Умножение 16-бит [HL] на 7 через DAD |
| 0x026A | `lbl_dispatch_return` | — | Очистка стека (POP PSW/D/H; RET) — общий возврат из диспетчера |

### 1.5. Игровая логика (ROM)

| Адрес | Имя | Размер | Описание |
|-------|-----|--------|----------|
| 0x0153 | `func_piece_dispatch` | — | Диспетчер фигур: DCR A, переход по значению (1–7) |

## 2. Распакованный код (0x0800+)

### 2.1. Основные функции

| Адрес | Имя | Размер | Описание |
|-------|-----|--------|----------|
| 0x0800 | `func_block_copy` | 163 | Копирование блоков по 16 байт через POP/MOV паттерн |
| 0x0803 | `func_data_load` | — | Функция загрузки данных, вызывается 4 раза из ROM (0x0104) |
| 0x0B57 | `func_main_init` | — | Основная инициализация: DI, SP=0x0100, очистка VRAM, вызов 0x0383, инициализация переменных |
| 0x0C65 | `lbl_title_key_poll` | — | Цикл опроса клавиатуры на заставке (LXI B,0C00; CALL 017C; JNZ 0C9D) |
| 0x0CA3 | `func_piece_div2` | — | Деление HL на 2 (4× RAR) через LHLD 0x08E9 |
| 0x0CE0 | `func_game_loop` | — | Игровой цикл: опрос клавиатуры, диспетчер фигур (1–7), инициализация фигур |
| 0x0EF7 | `func_vram_clear` | 25 | Очистка VRAM: цикл по 0x1000 байт через ANA/MOV |

### 2.2. Структура игрового цикла (0x0CE0)

```
0x0CE0: XRA A            ; обнуление
0x0CE1: CALL 017C         ; опрос клавиатуры
0x0CE4: CMP M             ; проверка результата
0x0CE5: JZ 0CF5           ; нет нажатия → пропуск
0x0CE8: LDA 0900          ; чтение состояния
0x0CEB: CPI 01            ; проверка режима
0x0CED: JZ 12B3           ; переход к обработке
0x0CF0: CPI 02
0x0CF2: JZ 12F6
...
0x0D42: CALL 0153         ; диспетчер фигур
0x0D45: CPI 01..07        ; проверка типа фигуры
0x0D47-0x0D65: JZ ...     ; переходы к:
  - 0x0D68 (типы 1,2)     ; инициализация
  - 0x0FD4 (типы 3,4)     ; движение вниз
  - 0x1042 (тип 5)        ; поворот
  - 0x1017 (типы 6,7)     ; движение влево/вправо
```

## 3. Таблица переходов (0x01CD)

16 записей, используемых диспетчером `func_jmp_table_dispatch`:

| № | Адрес | Действие |
|---|-------|----------|
| 0 | 0x01ED | STA 031A; CALL 0201 (sound_timer_write); JMP 026A |
| 1 | 0x01F7 | STA 031B; CALL 0201; JMP 026A |
| 2 | 0x0219 | STA 031C; CALL 022D; JMP 026A |
| 3 | 0x0223 | STA 031D; CALL 022D; JMP 026A |
| 4–11 | ... | STA 031E–0325; CALL sound_write; JMP 026A |
| 12 | 0x0271 | LXI H,031A; CALL 020E (mul7); JMP 026A |
| 13 | 0x0278 | LXI H,031C; CALL 020E; JMP 026A |
| 14 | 0x027F | LXI H,031E; CALL 020E; JMP 026A |
| 15 | 0x0286 | LXI H,0320; CALL 020E; JMP 026A |

**Паттерн:** Записи 0–11 устанавливают параметры звука в 0x031A–0x0325 и записывают в порт ВИ53. Записи 12–15 вычисляют значения через mul7.

## 6. Потоки данных (Data Flow)

### 6.1. Загрузка данных из ROM

```
func_rom_entry (0x0100)
  → JMP func_main_init (0x0B57)
    → CALL func_rom_init (0x0383) — настройка PIA, ISR, EI
    → SHLD 08DB — сохранение указателя данных
    → CALL func_data_load (0x0803) × 4 — загрузка блоков
```

### 6.2. Звуковой путь

```
func_sound_init (0x0121)
  → CALL func_jmp_table_dispatch (0x01BC) × 4
    → ANI 0F → data_jmp_table (0x01CD)
      → STA 031A–0325 (параметры)
      → CALL func_sound_timer_write (0x0201)
        → CALL func_mul7 (0x020E) — умножение × 7
        → OUT 0x0B — запись в ВИ53
```

### 6.3. Игровой цикл

```
func_game_loop (0x0CE0)
  → CALL func_keyboard_timer (0x017C) — опрос SPACE
  → LDA 0900 — состояние
  → CALL func_piece_dispatch (0x0153) — диспетчер фигур
    → CPI 1..7 → переходы к обработке
      → func_vram_clear (0x0EF7) — очистка
      → func_data_loader (0x01A1) — загрузка данных фигуры
      → func_block_copy (0x0800) — копирование
```

## 8. Выводы

1. **Жанр:** Tetris-клон. Порт с MSX (MSX MAGAZINE, 1987, by HI-SCORE) на Vector-06C.

2. **ROM компактен:** ~1.75 КБ (0x0100–0x07FF), распакованные данные занимают ~15 КБ (0x0800–0x45FF).

3. **Архитектура:** ROM содержит минимальный загрузчик + диспетчер + звуковой движок. Основная игровая логика — в распакованном коде (0x0800+).

4. **Звук:** Через КР580ВИ53 (порт 0x0B), значения умножаются на 7 перед записью. 12-байтная таблица параметров (0x031A–0x0325).

5. **Экран:** 256×256, 4 битплоскости, анимированный скроллинг на заставке.

6. **Управление:** SPACE — основная клавиша (опрос через IN 0x01, ANI 0x20).

7. **ISR:** Вектор на 0x0038 → JMP 0x03A4. Инкремент счётчика кадров.

8. **Стек:** SP = 0x00FE (нулевая страница RAM).
